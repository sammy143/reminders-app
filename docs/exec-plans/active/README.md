# Active exec plans

One file per in-flight multi-step feature: `<feature-id>.md`. Move to `../completed/`
when the feature passes.

## Template

```md
# <feature-id>: <title>

## Goal
<one or two sentences; link feature_list entry>

## Approach
- files/symbols to touch, layer by layer

## Decisions
- <choice> — <why> (date)

## Verify
- copy of the feature's verify steps + any extra

## Log
- <date>: <progress / blockers>
```
