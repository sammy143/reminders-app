# F001: Scaffold Expo + TypeScript + Expo Router + NativeWind with lint, typecheck, tests

## Goal
Runnable Expo app skeleton that all later features build on (harness/feature_list.json F001).

## Approach
- Generate with `npx create-expo-app` (TypeScript template) into the repo root without
  clobbering existing docs/harness/scripts; strip the example screens/components.
- Routes in `src/app/` (Expo Router); `tsconfig.json` strict + `@/` → `src/` alias.
- NativeWind v4: `tailwind.config.js` mirrors color/type tokens from `docs/design/DESIGN.md`;
  `global.css`, babel/metro config; placeholder `src/app/index.tsx` uses Tailwind classes.
- Scripts: `lint` (expo lint / ESLint), `typecheck` (`tsc --noEmit`), `test` (jest-expo).
- One trivial test so `npm test` is meaningful (e.g. a smoke test in `src/domain/`).
- Create empty layer folders only if needed; don't pre-build later features.

## Decisions
- Latest stable Expo SDK from create-expo-app; add libs with `npx expo install` (2026-09-24).
- Expo SDK 57 (expo 57.0.x, RN 0.86, React 19.2, TypeScript 6). Generated in a scratch dir
  (`create-expo-app --template default`) and copied in only package.json/lock, tsconfig, app.json
  and the icon/splash assets. The template's own AGENTS.md, CLAUDE.md, .claude/, README, LICENSE,
  reset-project script, example screens/components/hooks/constants were dropped, as were the
  unused deps (@expo/ui, expo-device, expo-glass-effect, expo-image, expo-symbols, expo-web-browser).
- NativeWind 4.2.7 + tailwindcss 3.4 (latest stable; v5 is still rc). Tokens in
  `tailwind.config.js` use DESIGN.md names: colors `bg surface ink ink-muted line primary tone-*`,
  font sizes `display title headline body label caption countdown` (with line height + weight),
  radii `rounded-card` (16) / `rounded-button` (12). Default Tailwind spacing already matches the
  4/8/12/16/24/32/48 scale.
- Fonts are declared (`font-heading`, `font-body`) but not loaded; placeholder uses the system
  font. Logged in docs/tech-debt.md.
- `global.css` lives at repo root (NativeWind default), imported from `src/app/_layout.tsx`.
- Placeholder screen is `src/ui/HomeScreen.tsx`, rendered by the thin route `src/app/index.tsx`.
  Reason: Expo Router treats every .tsx under `src/app/` as a route, so tests can't sit next to
  route files; keeping the screen in `ui/` lets its test live beside it.
- `nativewind-env.d.ts` also references `expo/types` so `*.css` imports typecheck on a fresh clone
  (the equivalent `expo-env.d.ts` is generated by `expo start` and gitignored).
  `tsconfig` sets `types: ["jest"]` because TS 6 no longer auto-includes @types packages.
- Lint = `expo lint --max-warnings 0` (eslint-config-expo flat + eslint-plugin-prettier);
  Prettier with `prettier-plugin-tailwindcss` for class ordering; `npm run format` writes.
- Test = `jest` with `jest-expo` preset (in package.json) + @testing-library/react-native 14.
- Environment: api.expo.dev is blocked by the sandbox egress policy, so `npx expo install` was
  run with `EXPO_OFFLINE=1` (versions resolved from the local expo package's bundled list).
- No change to scripts/check.sh or check-architecture.mjs was needed (it already skips
  node_modules/.expo/dist).

- `app.json` splash/adaptive-icon background hard-codes `#F7F7F5`: native config can't read Tailwind tokens; it must mirror the `bg` token (2026-09-24).
- `.prettierignore` covers docs/harness/agent files and `scripts/`; ESLint ignores `scripts/*` so lint and format scope match (2026-09-24).
